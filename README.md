Day 10: 
1. Database Fundamentals & ACID
  ->The "Digital Filing Cabinet": Why we use MS Access instead of simple Text Files (Concurrency, Security, Speed).


  ->ACID Properties: The four rules of reliability:


  ->Atomicity: The "All or Nothing" transaction (no partial charges).


  ->Consistency: Data must follow the rules (no negative stock).


  ->Isolation: Transactions don't "leak" into each other.


  ->Durability: Data survives a system crash.

2. Database Types & Architecture

  ->SQL (Relational): Table-based, strict, and perfect for your Inventory Tracker (MS Access, SQL Server).


  ->NoSQL (Non-Relational): Flexible, document-based for big data (MongoDB).


3. SQL Data Definition (Creating)

  ->CREATE TABLE: Defining the "Schema."


  ->Data Types: Using INT for counts, VARCHAR for text, and DECIMAL for money.


  ->Constraints: Using NOT NULL, UNIQUE, and DEFAULT to act as "Bouncers" for your data.

4. SQL Data Manipulation (Inserting)

  ->INSERT INTO: Adding new records to your tables.


  ->Syntax Rules: Matching column orders and using single quotes for text.


  ->AutoNumber/Identity: Letting the database handle the IDs automatically so you don't have to.
